# 강의시간의 불청객

강의실에 난입한 파리가 교수님의 파리채를 피해 간식 부스러기를 모으는 레트로 아케이드 게임입니다.

## 플레이

- `index.html`을 브라우저에서 열거나 GitHub Pages로 배포하세요.
- 방향키 또는 `W A S D`로 파리를 움직입니다. 모바일에서는 화면 아래 터치 버튼을 사용할 수 있습니다.
- 45초 동안 버티면서 간식을 모으고, 바닥에 표시되는 빨간 경고 구역을 피하세요.
- 최고 점수는 브라우저 로컬 저장소에 기록됩니다.

## 배포

빌드 단계나 외부 라이브러리 없이 동작하는 정적 웹사이트입니다. GitHub 저장소의 **Settings → Pages**에서 `Deploy from a branch`를 선택하고 `main` 브랜치의 `/ (root)`를 지정하면 공개할 수 있습니다.

배포 URL은 보통 `https://<사용자명>.github.io/<저장소명>/` 형식입니다.
